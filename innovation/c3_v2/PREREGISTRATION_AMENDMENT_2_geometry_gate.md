# 预注册修正案 2：几何通道闸门（GEOMETRY GATE AMENDMENT）

日期：2026-09-21（冻结于任何批次 DFT 数据产出之前）
状态：正式生效。冻结纪律：本修正案的理由全部基于已存在的 S4（innovation/real_geom/，Δ=+0.0249、G1 r=−0.16）与 Phase 5 CHGNet 特征（r=−1.12）证据，**与未来 DFT 批次结果无关**；先冻结、后重判，顺序不可颠倒。

## G1. 问题陈述

原可移植性闸门（portability_gate）的线 B 代理为"Ridge 组成线性可推断性"——检验候选特征能否由 36 个组成描述符在未见组成上线性推出。该代理隐含假设：被检特征的合法部署形态是"无结构输入"。

真实几何特征族的部署形态不同：其输入本来就是结构文件（弛豫 slab），不是无结构化学式。对几何通道应用"组成线性可推断性"代理，等于要求一个独立信息通道必须冗余于组成通道——这在概念上错配。S4（r=−0.16）与 Phase 5 CHGNet 特征（r=−1.12）的双双 LEAK，经两轮互证指向代理口径的系统性错配，而非特征本身泄漏。

## G2. 修正内容（仅一条，范围限定）

对**几何特征族**（且仅对几何特征族：由原子坐标直接计算的结构描述符，如 CN/GCN/层距/位移/rumpling/近邻统计），线 B 代理由

- 旧：组成线性可推断性（Ridge 保留率 ≥0.8）

替换为

- 新：**弛豫结构可得性**——特征在部署时可由无标签弛豫（DFT 或经锚定验证的 MLIP 预弛豫 + DFT 精修）独立获得，且特征计算管线对训练/未见组成使用同一确定性代码路径（无按标签分流的环节）。

适用范围显式排除：能量族特征、任何含目标值派生量的特征、组成描述符族（继续适用旧线 B）。

## G3. 防滥用条款

1. 本修正案不构成对 S4 之外任何历史 LEAK 判定的追溯翻案；Phase 5 弛豫组（subset_signal_gate_failed）的判定因其 14% 覆盖与代理势伪影问题维持不变。
2. 通过新闸门仅解除"口径性 LEAK"，不解除公平契约：采纳仍需 Δ>0.005 eV + 10/10 种子 + 嵌套 CV 复核。
3. 若未来 DFT 批次数据显示真实几何特征在真实复弛豫构型上失效，本修正案的采纳结论可被新数据推翻——但推翻依据必须是新预注册的评估，不是回调闸门。
