# Workstream J：可信锚点库 + 评估机器 Agent（协议级交付，v1.0）

范围说明：J1 的 LLM 初筛规模化与两人人工审计需要外部文献工时，J2 的 Agent 上线需要部署资源；本文件将两者的协议、数据规范与红线预注册，作为执行蓝图与方法论交付（红线 12/13）。

## J1 锚点库规模化协议

目标：文献吸附能锚点从 25 扩至 200+，覆盖 15 吸附种中至少 5 种，发布为可复核基准。

**流水线**：LLM 初筛提取（候选文献 → 数值、上下文、物理量类型判定）→ 人工审计闸门 → 入库。

**审计链必填字段（缺一字段不入库，红线 12）**：
| 字段 | 说明 |
|---|---|
| doi / 原文页码 | 来源定位 |
| value_context | 数值上下文原文引文或截图指针 |
| quantity_type | 物理量类型判定（E_ads / ΔG / 活化能等） |
| surface / adsorbate / functional | 体系标注 |
| reviewer_1 / reviewer_2 | 两人独立核对签名 |
| llm_raw / human_final | LLM 初值与人工终值（不一致即弃件） |
| ingest_time | 入库时间戳 |

**反幻觉条款**：LLM 输出不得直接入库；数值与原文不符即弃；弃件率本身作为流程质量指标随库发布。宁可少而准（3.8 节纪律延伸）。

## J2 评估机器 Agent 封装规范

**架构**：现有 web 引擎（v3 推理 + P_near + 红旗标注 + 可移植性闸门 + 锚点库）注册为 tool-calling 工具集；LLM 仅做意图理解与编排。

**核心红线（13）**：所有数值回答必须经工具调用返回，LLM 禁止直接生成数字（含演示）——直接回应 ChemCrow 类规划型智能体的数值幻觉软肋；本 Agent 的每个数值都带校准概率与审计链。

**预注册演示场景（3 个，防止按结果挑）**：
1. 「找无红旗的近热中性双金属」→ 触发候选带查询 + 红旗过滤；
2. 「这个组成的预测可信吗」→ 触发域内/外判定 + P_near + 锚点交叉验证；
3. 「这个反应的 ΔG 有没有文献锚点」→ 触发锚点库检索（含审计链展示）。

**留档**：全部工具调用日志入库；演示失败也如实展示日志。

## 与谱系定位的关系

谱系 A（LLM 智能体编排）有编排无可靠数值；本工作包把 Phase 1–3 攒下的评估机器（三层测试 / 闸门 / conformal / 逃逸角红旗）变成 Agent 的可信工具层——「借谱系 A 的编排，打自己生态位的仗」。
