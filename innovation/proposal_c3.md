# C-3 闭环补算提案包（第一轮 DFT 补算）

版本：v1.0（R15，Phase 2）· 口径：有序 fcc 系表面、组成级模型、演示级自由能修正

## 一、提案依据（三条证据链）

1. **主动学习收益**：回溯与外部代理双重验证表明，补算 20 个同口径点可使外部误差下降约 18%（交付文档 3.12/3.16 节）。
2. **噪声地板**：误差解剖探针 P3 测得 floor_a = 0.0366 eV（floor_b = 0.1163 eV），界定补算的边际收益上限——当前模型距理论地板仍有约 0.08 eV 缺口，但该缺口由 P4 定位为**位点信息**（Δ_A = 0.0391 eV LEAK 红利），非架构容量。
3. **逃逸角双重警示**（3.23 节）：最接近 HER×ORR 双优区的 20 个候选中 16 个（80%）带 ≥1 红旗（La/Y/Sc 强亲氧 14、Mn/Bi/Fe LOEO 5、Tl 毒性 1），且 100% 位于 OH* 训练域之外——逃逸角既是模型外推的不可信区，也是材料稳定性的高风险区。

## 二、首轮补算清单生成规则（预注册）

1. **红旗候选一律不进首轮**（强亲氧 / LOEO 外推 / 毒性任一类即排除）。
2. 首轮 20 个补算点由两半构成：
   - **10 个**：主动学习采集函数（不确定度 × 期望改善）顶部候选；
   - **10 个**：H→OH 标度线（ΔG_OH = 1.384·ΔG_H + 3.332）最近邻且无红旗的第二梯队候选——直接检验 d_min 裁决边界。
3. **全部补算点强制记录位点级连续特征**：各位点类型的配位数、几何参数（键长/层距）、d 带中心。依据：C-2（3.24 节）定量证明红利兑现率仅 14.7%，缺口在同位点类别内的连续能量差异（mean−min 中位 0.193 eV）。
4. 计算协议与 Mamun 2019 主训练域保持同口径（泛函、截断能、k 点、自由能修正），否则补算点无法并入训练集。

## 三、验收判据（预注册）

- 补算后重训 v3 同协议：外部集（EqV2-HER）MAE 下降 ≥15% 视为闭环成立；
- 位点级连续特征入模后重跑 F3：位点级 OOF MAE ≤ 0.090 eV 且不低于 0.077 eV（泄漏嫌疑线）；
- 第二梯队标度线最近邻候选的实测 ΔG 分布与模型预测的方向一致率 ≥ 70%。

## 四、纪律条款

- lockbox 纪律不变：任何新模型在 lockbox 上只允许单次裁决评估；
- 公平契约不变：相对 v3 改善 >0.005 eV + 10/10 种子方向一致 + 嵌套 CV 双过，方可更换交付模型；
- 本提案包不引入任何新数据，仅为下一轮实验/计算的执行蓝图。


## 五、与自主发现争议事件的区分（A-Lab 教训）

A-Lab 事件（17 天 43 种新材料的自主性宣称因 XRD 物相鉴定争议被 Nature 更正）表明：自主性主张必须越过比标题指标更高的表征门槛。本提案对应的三重区分设计：

1. **事前公开清单 + 时间戳**（已有，第二节）：补算对象在计算前冻结，禁止按结果挑；
2. **锚定闸门先行**（已有）：BEEF-vdW 同协议复算 5–10 个已知体系，|ΔE|≤0.1 eV 方放行；
3. **独立复算条款（新增）**：全部新点的结构弛豫由第二脚本/第二人独立复核，结构鉴定标准（收敛判据、对称性保持、能量一致性）事先写死；两轮结果不一致的点不入学，仅记录为争议样本。

预注册 + 审计链不仅是风控，也是方法论卖点：在自主发现公信力受审视的当下，这套纪律本身即贡献。
