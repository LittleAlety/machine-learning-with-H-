    03 · OVERVIEW

    火山图总览

    训练集 1836 条位点的样本外（OOF）预测结果全景。横轴与纵轴均为导出量而非原始测量：x 为 OOF 预测 ΔGH*，y 为其负绝对值（Sabatier 活性代理，越接近峰顶 0 越好）。在预测器中查询组成后，对应位点会在图上高亮。

    着色方式：
    数据来源：predictions_all.json（训练集 OOF 预测）。x 轴标签「ΔG_H*（导出量）= E_ads + 0.24 eV」，y 轴「−|ΔG_H*|（导出量，活性代理）」。
    预测 ΔGH*（导出量）分布直方图。阴影区 |ΔGH*| ≤ 0.1 eV 为「优秀候选」窗口。
    04 · METHOD & LIMITS

    方法与边界

    模型：XGBoost 回归（400 棵树，max_depth=7，η=0.03），输入为 84 个元素描述符（13 项元素属性的加权统计与众数 + 结构/晶面 one-hot），目标为最稳定位点 H* 吸附能 E_ads。当前上线版本（v3，84 特征）的分组样本外（OOF）MAE = 0.1134 eV；下表为上一代 36 特征模型（v2）的四种验证口径 MAE（单位 eV），供口径对比参考：

    评估口径MAE (eV)说明
    v3（84 特征）GroupKFold 样本外（OOF）0.1134当前上线模型；候选表与火山图均为此口径预测
    v2 随机 5 折交叉验证0.120 ± 0.011随机划分，含组成/位点泄漏，偏乐观
    v2 GroupKFold（按组成分组）0.120同一组成的不同位点不跨折，更接近真实泛化
    v2 LOEO（留一元素外推）0.155对未见元素的外推能力，诚实下限

    v2 CatHub 同质外部验证0.177与训练集同源数据库的独立样本验证
    SHAP 全局特征重要性（mean |SHAP|，单位 eV，对 1836 条训练样本的 TreeExplainer 结果）。族号与熔点类描述符主导预测，与 d 带理论的物理直觉一致。
    • 定位：本工具在训练域内（37 种元素、A1/L1₀/L1₂ 表面）是定量工具（样本外 OOF MAE ≈ 0.113 eV）；跨数据库或域外组成仅为粗筛参考，预测器会以徽标明确标示外推情形。
    • 候选簇：候选榜单头部为统计上不可区分的一组位点（预测差异 < 0.01 eV，远小于模型误差），排名先后不构成优先级依据。
    • 位级一致：浏览器端推理引擎与 Python XGBoost 参考实现逐位比对，20 个校验用例（84 特征，含域外组成与 mode 平局）预测与特征 max diff = 0（float32 逐步累加与分裂比较严格对齐，校验页：parity_check.html）。

    WHY THIS LOOP EXISTS

    一个 40 倍弛豫伪影的预裁证据

    Phase 5 用 CHGNet 预弛豫时报告了剧烈表面重构。对 25 个候选体系的原子级直接预裁显示：25/25 为 ARTIFACT，而非真实重构。DFT 锚定的顶层层均位移中位数仅 0.117 Å（区间 0.022–0.403 Å），而 CHGNet 报告 3.503 Å——约 40 倍高估。8 个哨兵的 DFT 弛豫就是为了在回灌前把这个伪影钉死。

    FEATURE ABLATION

    静态成分描述符已经饱和

    文献提出大量元素/体相描述符。我们在同一公平契约下（按规范化成分 GroupKFold、固定调参、3 种子；筛选基线 MAE 0.1166 eV）筛选了三个独立家族，没有任何一个能带来可靠增益，故均不并入生产模型。

    Δ −0.0004 eV
    Materials Project 弹性模量 K/G/各向异性
    Δ +0.0002~+0.0008
    OMat24 元素体相参考能量/原子

    所有静态描述符 Δ 均在 ±0.0016 eV 内（远小于折间波动 ~0.01 eV），合并加入反而中性或变差。缺失的信息是只有弛豫才能返回的表面几何与局域电子结构——这正是需要 DFT 回灌、而非继续堆静态特征的原因。
