## 1. 稳健候选簇（c × 模型 18 名单交叉）

**方法**：c ∈ {0.20, 0.21, …, 0.28}（9 值）× {v2 OOF（36 特征，`calib_oof_predictions.csv:pred_base`）、
v3 OOF（84 特征，`web/assets/predictions_all.json:pred_E_ads`）} 共 18 个名单；
ΔG = pred + c，按 |ΔG| 升序取 Top-50。去重口径 = 22 号脚本 §3 现行口径 (i)
（组成得分 = min|ΔG|，groupby-min 实现）；实证上 v2/v3 数据集均为
1,836 行 = 1,836 唯一 comp（每组成恰 1 行），去重平凡成立。

**结果（核心发现：无稳健 Top-50 候选）**：

- 进入过任一名单的候选共 **209 个**；出现次数分布：8 次 13 个、7 次 25 个、
  6 次 29 个、5 次 16 个、≤4 次 126 个。
- **A 级（≥16/18）= 0 个；B 级（≥9/18）= 0 个；全部 209 个均为 C 级**。
  模型内稳定性同样为零：v2 的 9 个 c 名单中全勤（9/9）的候选 0 个；v3 亦 0 个。
- 出现次数最多（8/18）的 13 个候选：CuPd3、PtZn、Au3W、InPd3、AuPt、Al3W、
  Au3Mo、CoPd3、CuPd、Ir3Ni、AlPt3、RhTl、Al3Sc（全部 L1₂(111)/L1₀(101)，
  |ΔG| 中位数 0.021–0.027 eV，范围见 `r9_robust_cluster.csv`）。
- **c=0.24 默认口径下 v2∩v3 Top-50 交集仅 11/50**。
- 自洽性核对：v3 OOF c=0.24 Top-3 = IrOs3/Au3Rh/BiZr（与 `candidates_top.json` 一致）；
  CuPt3 不在 v3 Top-50（与"v2 榜首跌出 Top-50"一致）。
  注意口径差：`candidate_rankings_hstar.csv` 的 v2 榜首 CuPt3 用的是**全量拟合**预测
  （−0.2402 eV）；v2 OOF 口径下 CuPt3 预测 −0.2520 eV（|ΔG|=0.012，仍在 Top-50
  但非第 1；v2 OOF c=0.24 榜首为 Ir3Rh）。

**机理（为何零稳健）**：近峰带极度拥挤——c=0.24 时 Top-50 的 |ΔG| 阈值仅
0.017 eV（v2）/ 0.019 eV（v3），|ΔG|≤0.05 eV 的组成有 145（v2）/ 135（v3）个；
而 OOF MAE ≈ 0.12 eV，即 **Top-50 成员资格由约为 1/6 个 MAE 的差值决定，
远低于模型分辨力**。c 每移动 0.01 eV 即换一批成员。这与 Round 5
"Top-20 随 c 完全更换但全局 Spearman 0.990–0.998" 一致并更严厉：
**全局排名稳健 ≠ 榜首名单稳健**；文档中任何具体 Top-N 名单都应表述为
"近峰带（约 140 个组成）中的示例性成员"，而非稳定结论。

## 3. 小数字核实（详见 `outputs/r9_small_numbers.md`）

**3a. OOF 残差 |residual| ≤ 0.2 eV 占比**（文档图 1 只说"占绝大多数"）：
- v2（36 特征）：**1,579/1,836 = 86.00%**（≤0.1 eV：67.92%；median |r| = 0.0561）
- v3（84 特征）：**1,610/1,836 = 87.69%**（≤0.1 eV：71.19%；median |r| = 0.0509）

**3b. "0.180→0.120 降 34%"核实**：0.180 出自 deprecated/成果汇总报告 §4.2 的
**随机 5-fold** 模型对比（`hstar_model_compare.csv`：Ridge 0.180159，Linear 0.180746，
XGBoost_tuned 0.120263；注意此口径非 GroupKFold OOF 0.1198）。
精确降幅 = (0.180159−0.120263)/0.180159 = **33.25%**；vs Linear 33.46%；
按舍入值 0.180→0.120 = 33.33%。**文档"34%"有误，应改为约 33.3%（或 33%）**。

**3c. EqV2 Spearman ρ=0.17–0.29 的分层还原**（从 `extval_results.csv` 逐层重算）：
文档引用的两层 = **ALL 491：ρ=0.1735** 与 **eqv2_361_relaxed 219：ρ=0.2915**。

域内晶面层（facet=111）排序能力实际为 0，文档引用区间时建议补充此层。

**3d. Cathub 7,005 vs 7,048 的 43 条去向**（本地重算，未访 API）：
镜像 H* 构型 7,048 条 / 1,836 组成；能量逐条核对只对**组成交集**（1,821 个）内的
镜像构型计数，分母 n_total=7,005。**差值 43 = 15 个"仅镜像"组成（AgFe3, AgTc,

## 4. min-聚合极值偏置量化（`hstar_group_spread.csv`，可检验）

数据集**确实存在**同 comp×structure 多构型记录：1,836 组中 1,746 组（95.1%）
由 ≥2 条构型取 min 得到标签（n_raw 中位数 4，最大 10；仅 90 组 n_raw=1）。

- 多构型组中 min 相对均值的下移（E_mean − E_min ≥ 0）：
  均值 **0.275 eV**，中位数 **0.214 eV**，p25/p75 = 0.102/0.400，p95 = 0.701 eV；
  相对中位能的下移（E_median − E_min）均值 0.210、中位 0.117 eV。
- 对筛选的实际影响：|ΔG|≤0.1 eV 的表面数，min 口径（现行）**248 个** vs
  mean 口径 **359 个**；两口径 |ΔG| 排名 Spearman 仅 **0.563**
  （引自 22 号脚本 Panel B 结论的量化复核）。
- 近峰簇（min 口径 |ΔG|≤0.1，248 个）中 97.98% 为多构型组，
  其标签下移中位数 0.173 eV。

**结论：审稿猜想成立**。标签 = 多位点 min 使能量系统性偏低约 0.2–0.3 eV
（中位 0.21 eV），幅度与模型 OOF MAE（0.12 eV）同量级甚至更大，且直接作用于
|ΔG| 近峰判定（min 口径把近峰池从 359 压缩到 248）。这是与"任务 1 榜首零稳健"
并列的候选名单不确定性来源，建议在文档局限性中量化引用。
